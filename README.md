## Sobre o Projeto

Este projeto consiste em um site de perfil pessoal, desenvolvido com o objetivo de apresentar informações básicas como quem sou, formação, cursos e formas de contato.

O site foi criado utilizando HTML e CSS, com foco em:

Estruturação de páginas web

Estilização básica e layout responsivo

Organização visual de informações pessoais

Prática de navegação entre páginas

Este projeto faz parte do meu processo de aprendizado em desenvolvimento web e é utilizado como material de apresentação acadêmica e profissional, 
especialmente para oportunidades de estágio.
